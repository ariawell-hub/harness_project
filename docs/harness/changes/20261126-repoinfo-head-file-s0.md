# 변경 조각: 20261126-repoinfo-head-file-s0

## CHANGELOG

- `repoInfo`가 첫 커밋 전 브랜치의 작업 트리에 `HEAD`라는 파일이 있어도 브랜치 이름을 `HEAD`로 내지 않는다(Issue #252, #236의 회귀를 고쳤다): git 한 번으로 읽는 빠른 경로의 인자 끝에 `--`를 붙여 `HEAD`를 리비전으로만 읽고, 출력의 다섯째 줄이 정확히 `--`일 때만 그 값을 쓴다. 그 밖에는 예전 두 번 읽기(`rev-parse` → `symbolic-ref`)로 읽는다. 커밋이 있는 리포의 보통 경우에 git을 한 번만 띄우는 것은 그대로다(Issue #230).
