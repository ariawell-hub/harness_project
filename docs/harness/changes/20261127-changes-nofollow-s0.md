# 변경 조각: 20261127-changes-nofollow-s0

## CHANGELOG

- `changes-collect`가 쓰기·지우기 직전마다 `docs`·`docs/harness`·조각 폴더와 기록 파일이 시작 검사 때의 그것(dev·ino)인지 보고, 기록 파일은 링크를 따라가지 않고 연 핸들로 한 번 읽어 그 바이트로 HEAD 확인·모으기·변경 확인을 하고, 쓰기는 확인한 핸들로, 조각 지우기는 조각 폴더를 작업 폴더로 삼아 이름으로 한다(Issue #257, PR #254 판정 F4). 그 사이 기록 파일이나 상위 폴더가 같은 바이트의 리포 밖 파일·폴더로 가는 링크나 하드 링크로 바뀌면 링크 너머를 바꾸거나 지우지 않고 멈춘다. `O_NOFOLLOW`가 없는 Windows에서도 식별자 비교로 막는다.
