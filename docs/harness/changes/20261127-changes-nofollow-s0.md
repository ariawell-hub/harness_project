# 변경 조각: 20261127-changes-nofollow-s0

## CHANGELOG

- `changes-collect`가 동시에 같은 작업 트리를 바꾸는 다른 프로세스와 링크로부터 기록을 지킨다(Issue #257, PR #254 판정 F4). 기록 파일은 링크를 따라가지 않고 연 핸들로 한 번 읽어 그 바이트로 HEAD 확인·모으기·변경 확인을 한다. 쓰기·지우기는 `docs/harness`·조각 폴더를 작업 폴더로 고정하고, 원래 파일을 이 실행만 아는 임시 이름으로 옮겨 식별자(dev·ino)·링크 수·내용을 다시 본 뒤, 결과를 새 파일의 핸들에 써서 덮어쓰지 않는 하드 링크로 게시하거나 조각을 지운다. 어긋나면 덮어쓰지 않고 제자리로 돌려놓고 멈춘다. 되돌리는 명령은 알릴 때 그 자리가 이 명령이 남긴 그대로인 파일만 담고, 나머지는 "자동으로 되돌리지 않는 파일"로 알린다. `O_NOFOLLOW`가 없는 Windows에서도 식별자 비교로 막는다.
