# 변경 조각: 20261125-selftest-parallel-s0

## CHANGELOG

- 하네스 자체 테스트(`self-test`)가 시나리오를 시나리오마다 자식 프로세스로 나란히 돌린다(동시 수 기본은 코어 수, `--jobs`). 시간 제한을 넘긴 자식은 자손까지 끝내고, 나란히 돌 때 `pass`가 아닌 시나리오는 혼자 한 번 더 돌린다(시간 제한으로 끝낸 시도가 생기면 그 뒤로는 다시 돌리지 않는다). 보고서 형식과 시나리오는 그대로다(ADR-0008 F2, Issue #247).

## 설계서 변경 이력

- 12.4절: LLM 없는 시나리오를 자식 프로세스로 나란히 돌리는 방식(동시 수, 시간 제한이 긴 것부터, 자식의 시간 제한과 자손 정리), 나란히 돌 때 실패한 시나리오를 혼자 다시 돌리는 규칙(시간 제한으로 끝낸 시도가 생기면 멈춤)과 그 이유, 실행 명령의 `--jobs`와 요약 줄을 적었다(Issue #247)
