# 게임 프로파일 (초안)

로드맵 5단계에서 착수한다. 웹으로 코어가 안정된 뒤 시작한다(15절).

- **엔진(Q1)**: Godot을 우선 검토한다. 씬 파일이 텍스트라 diff·리뷰가 쉽고(B1), 헤드리스 CLI로 검증할 수 있으며(B5), 라이선스 비용이 없다.
- **표준 명령**: 엔진 헤드리스 CLI로 `test`(결정적 시뮬레이션: 고정 시드·고정 틱), `build`(헤드리스 익스포트)를 구현한다. 하네스 스크립트는 Node로 엔진 바깥에서 돈다(ADR-0001).
- **아키텍처**: 순수 게임 로직과 엔진 의존 코드를 분리한다(시뮬레이션 코어 / 엔진 어댑터 / 표현).
- **경로별 최소 위험도**: 에셋만 → 낮음, 게임 로직 → 보통, 세이브 데이터 형식·결제 → 높음.
- **verify**: `game-verify` 스킬(입력 리플레이, 프레임 캡처 비교).
- **고유 사항**: 대용량 에셋(Git LFS), 에셋 임포트 규칙, 프레임 시간 예산, 빌드 시간, Windows·macOS 러너 비용(Q16).
